# ⚡ Stax — Intelligent Tab Management

> **Stax** turns browser tab chaos into organized, color-coded tab groups automatically—with zero setup required.

---

## 🎯 The Problem
We’ve all been there: 40 tabs open, context switching between code docs, Spotify, YouTube, and banking, completely losing track of where anything is. Manual tab grouping takes too much effort, so tabs just pile up.

## ✨ 3 Key QoL Improvements
1. **Zero-Setup Local Domain Classifier:** Works out-of-the-box using lightweight regex pattern matching. Automatically groups dev tools, finance, communication, media, and reference sites without sending data anywhere.
2. **On-Demand AI Context Grouping:** For complex, mixed workflows, click one button to have Claude or Gemini analyze tab titles and hostnames to create human-readable, context-aware groupings.
3. **Non-Intrusive & Fast:** Operates as a Manifest V3 service worker. Debounced sorting prevents lag, and strict local storage keeps your API keys and browsing activity entirely private.

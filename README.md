# ⚡ Stax — Intelligent Tab Management Engine

[ English ] | [ [Deutsch](#-deutschland--german) ]

> **Stax** turns browser tab chaos into organized, color-coded tab groups automatically—with zero setup required.

---

## 🎯 The Problem
We’ve all been there: 40 tabs open, context switching between code docs, Spotify, YouTube, and banking, completely losing track of where anything is. Manual tab grouping takes too much effort, so tabs just pile up.

## ✨ 3 Key QoL Improvements
1. **Zero-Setup Local Domain Classifier:** Works out-of-the-box using lightweight regex pattern matching. Automatically groups dev tools, finance, communication, media, and reference sites without sending data anywhere.
2. **On-Demand AI Context Grouping:** For complex workflows, click one button to have Claude or Gemini analyze tab titles and hostnames for context-aware groupings.
3. **RAM Saver & Duplication Cleaner:** Instantly closes duplicate URLs across windows and runs quietly on Manifest V3 with a dedicated `Alt+S` hotkey.

## 🇩🇪 Deutschland / German

> **Stax** verwandelt das tägliche Browser-Tab-Chaos automatisch in strukturierte, farbcodierte Tab-Gruppen — ganz ohne Einrichtung.

### 🎯 Das Problem
40 offene Tabs, ständiges Wechseln zwischen Doku, Musik, YouTube und Online-Banking. Man verliert völlig den Überblick. Manuelles Gruppieren dauert zu lange, wodurch Tabs einfach liegen bleiben.

### ✨ Die 3 wichtigsten QoL-Funktionen
1. **Lokale Kategorisierung ohne Setup:** Nutzt intelligente RegEx-Muster zur sofortigen Sortierung von Entwickler-Tools, Finanzen, Medien und Wikipedia — komplett ohne API-Key.
2. **KI-Kontext-Sortierung auf Knopfdruck:** KI-Modelle (Gemini/Claude) analysieren Seitentitel und fassen zusammengehörige Themen intelligent zusammen.
3. **RAM-Schoner & Duplikat-Filter:** Entfernt doppelte Tabs mit einem Klick und bietet ein globales Tastatur-Kürzel (`Alt+S`).
